# OnePage_CasaFacilPratica

## Sobre o projeto
Este projeto foi desenvolvido para minha mãe, que possui uma página no Instagram voltada para divulgar achadinhos, ofertas e produtos interessantes.

## Por que escolhi esse projeto?
Escolhi fazer esse site porque queria criar algo que realmente tivesse utilidade no dia a dia da minha família. Como minha mãe já divulga achadinhos pelo Instagram, pensei que um site poderia ajudar a organizar melhor os produtos e facilitar o acesso das pessoas às recomendações.

## Como utilizei a IA?
Utilizei a inteligência artificial como uma ferramenta de apoio durante o desenvolvimento. Com ela, consegui transformar minhas ideias em um site, ajudando na criação do visual, na organização das páginas e em algumas partes do código.

Minha intenção não foi apenas pedir para a IA criar um site, mas também orientar o que eu queria, testar as sugestões e fazer alterações até chegar a um resultado que combinasse com a proposta.

## Objetivo
Criar uma página simples, organizada e fácil de usar, que ajude minha mãe a divulgar seus achadinhos e alcançar mais pessoas.
